# INOVAWEB Tracking — distribuição

Este repositório **não tem código-fonte**: ele guarda apenas o que os sites dos clientes precisam para instalar e
se atualizar. É escrito automaticamente pelo GitHub Actions a cada nova versão. Não edite à mão.

| Arquivo | Para quê |
|---|---|
| [`inovaweb-tracking.zip`](inovaweb-tracking.zip) | Versão mais recente do plugin (instalar em *Plugins → Adicionar novo → Enviar plugin*). |
| [`releases/`](releases) | Zip de cada versão publicada (para voltar a uma versão anterior). |
| [`update.json`](update.json) | Lido pelo próprio plugin em cada WordPress para oferecer "Atualização disponível". |
| [`Manual-INOVAWEB-Tracking.pdf`](Manual-INOVAWEB-Tracking.pdf) | Manual de uso com imagens. |

Plugin da **INOVAWEB** (Inova Web Design) — equipe@inovawebdesign.com.br.
